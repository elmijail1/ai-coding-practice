## 🤷‍♂️ What's the point?
LLMs can improve the speed at which you're developing apps by handling "how exactly do I write this?" issues, leaving you mostly just the "how do I build the app?" ones. Not only does it accelerate the whole app building process, but also it helps you focus on what matters most in the process. I see that as a welcome focus shift, and I'm willing to become better at using LLM tools.
